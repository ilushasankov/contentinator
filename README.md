# 📜 Contentinator

**Твой ультимативный инструмент для управления творческими идеями.**

[Скачать актуальную версию (APK)](https://ilushasankov.github.io/contentinator/)

---
Логистический хаб для криэйторов, SMM-менеджеров и блогеров. Порядок в идеях, сценариях, рубриках и рекламных компаниях — в одном приложении.

## 🔒 Безопасность и проверка подлинности

Если хотите быть уверены в безопасности приложения — вот данные для проверки целостности APK-файла.

### 1. Проверка хеш-суммы (SHA-256)
Убедитесь, что скачанный файл не был изменен. Хеш актуальной версии:
`B39D4AC64F7FEF897B89CD7DFBEAFE4E66B357B19C337AA99EF77862FA439FC4`

<details>
<summary>Инструкция по проверке</summary>

*   **Windows (PowerShell):** `Get-FileHash Contentinator_v1.1.1.apk -Algorithm SHA256`
*   **Linux/macOS:** `sha256sum Contentinator_v1.1.1.apk`
</details>

### 2. Проверка цифровой подписи
Приложение подписано разработчиком Ilya Sankov. Вы можете проверить сертификат командой:
`apksigner verify --print-certs Contentinator_v1.1.1.apk`

## 🛠 Разрешения (Permissions)
Приложение запрашивает минимум необходимых разрешений:
* **Интернет (`INTERNET`)** — для загрузки контента и работы с внешними сервисами.
* **Уведомления (`POST_NOTIFICATIONS`)** — чтобы присылать важные напоминания (для Android 13+).
